          Empat Komponen Utama
        

        

          Pondasi Arsitektur Model Context Protocol
        

        

          MCP dibangun di atas empat konsep fundamental yang memungkinkan AI berinteraksi secara aman dengan lingkungan eksternal.
        

      


      
      

        
        
        

          

            

              
            

            

              Tools (Alat Eksekusi)
            

            

              Fungsi yang dapat dipanggil oleh model AI untuk melakukan tindakan nyata, seperti menjalankan query SQL, membuat commit Git, atau mengirim notifikasi.
            

          

          

            tools/call • schema JSON
          

        


        
        

          

            

              
            

            

              Resources (Sumber Data)
            

            

              Konteks pasif berupa URI terstruktur (file://, db://) yang dapat dibaca LLM seperti berkas konfigurasi, log aplikasi, atau skema database.
            

          

          

            resources/read • URI scheme
          

        


        
        

          

            

              
            

            

              Prompts (Template Kontekstual)
            

            

              Template prompt siap pakai yang disediakan server untuk membantu pengguna menjalankan alur kerja kompleks dengan panduan teruji.
            

          

          

            prompts/get • reusable flow
          

        


        
        

          

            

              
            

            

              Sampling (Agentic Loop)
            

            

              Fitur canggih di mana server dapat meminta model AI untuk melakukan penalaran berulang atau penalaran sub-tugas dalam batas aman.
            

          

          

            sampling/createMessage

          Mulai Membangun
        

        

          Membuat MCP Server Pertama Anda dalam 3 Menit
        

        

          Ikuti langkah sederhana menggunakan SDK resmi TypeScript atau Python, atau langsung pasang server siap pakai ke Claude Desktop / Cursor.
        

      


      
      

        
        
        

          

            
            
            
          


          

            
            
            
          

        


        
        

          
          
// 1. Install MCP SDK
npm install @modelcontextprotocol/sdk

// 2. Buat server sederhana (src/server.ts)
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { CallToolRequestSchema, ListToolsRequestSchema } from "@modelcontextprotocol/sdk/types.js";

const server = new Server({ name: "my-mcp-server", version: "1.0.0" }, {
  capabilities: { tools: {} }
});

// Daftarkan tool
server.setRequestHandler(ListToolsRequestSchema, async () => ({
  tools: [{
    name: "calculate_tax",
    description: "Hitung PPN atau pajak transaksi",
    inputSchema: {
      type: "object",
      properties: { amount: { type: "number" } },
      required: ["amount"]
    }
  }]
}));

// Jalankan via stdio
const transport = new StdioServerTransport();
await server.connect(transport);

        


        
        

          
          
# 1. Install Python MCP SDK
pip install mcp

# 2. Server Python dengan FastMCP (server.py)
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("Demo Server")

# Definisikan tool dengan decorator sederhana
@mcp.tool()
def get_weather(city: str) -> str:
    """Dapatkan cuaca terkini untuk kota tertentu."""
    return f"Cuaca di {city}: 28°C, Cerah Berawan"

if __name__ == "__main__":
    mcp.run()

            Keamanan Enterprise
          

          

            Dirancang dengan Keamanan Lokal-Utama (Local-First)
          

          

            Data rahasia perusahaan tidak pernah bocor ke server pihak ketiga tanpa persetujuan eksplisit.
          

          
    
            
  • 
              
              Human-in-the-loop: Pengguna harus menyetujui pemanggilan tool
            
    • 
            
  • 
              
              Isolasi Sandbox: Pembatasan path direktori lokal ketat
            
    • 
            
  • 
              
              Stdio Transport: Komunikasi lokal tanpa membuka port jaringan
            
    • 
          

        


        

          

            

              
            

            
Batasan Akses Granular

            

              Tentukan izin read-only atau read-write per-koleksi data. Server MCP tidak dapat mengakses file di luar whitelist direktori yang ditentukan.
            

          


          

            

              
            

            
Audit Trail & Observability

            

              Seluruh request JSON-RPC 2.0 dapat dicatat ke file audit log lokal dengan timestamp, argumen fungsi, dan respons eksekusi.
            

          


          

            

              
            

            
Fleksibilitas Stdio vs SSE

            

              Gunakan stdio untuk performa sub-proses lokal nol latensi, atau SSE (Server-Sent Events) untuk microservices terdistribusi.
            

          


          

            

              
            

            
Dukungan Multi-Model

            

              Tidak terikat pada satu vendor LLM. Protokol bekerja sama baiknya dengan Claude, GPT-4, Llama lokal, Mistral, dan Gemini.
            

          

        


      


    

  


  
  

    

      
      

        

          
          Tanya Jawab
        

        

          Pertanyaan yang Sering Diajukan
        

        

          Semua yang perlu Anda ketahui mengenai lisensi, kompatibilitas, dan penerapan Model Context Protocol.
        

      


      
      

        
        
        

          
          

            Model Context Protocol (MCP) adalah standar terbuka yang dipelopori oleh Anthropic pada akhir 2024. MCP dirancang sebagai protokol universal yang menjembatani asisten AI (seperti Claude, Cursor, Antigravity, dan AI Agents) dengan berbagai sumber data eksternal (database, berkas lokal, devtools, dan API).
          

        


        
        

          
          

            Function Calling biasa hanyalah format skema JSON yang dikirimkan ke model. Anda tetap harus menulis kode runtime, menangani autentikasi, dan memelihara konektor untuk masing-masing aplikasi. MCP adalah protokol lengkap yang mencakup discovery dinamis (`tools/list`), stream data terisolasi, manajemen konteks pasif (`resources`), template (`prompts`), dan transport aman lokal via stdio/SSE.
          

        


        
        

          
          

            Ya! Spesifikasi protokol dan SDK resmi MCP (TypeScript, Python, Kotlin) dirilis di bawah lisensi terbuka (MIT License). Anda bebas menggunakannya untuk proyek pribadi, open-source, maupun enterprise komersial tanpa biaya royalti.
          

        


        
        

          
          

            Daftar client resmi dan komunitas terus bertambah pesat, meliputi Claude Desktop, Cursor IDE, Zed Editor, Google Antigravity, Sourcegraph Cody, serta berbagai framework AI agent seperti LangChain, LlamaIndex, dan AutoGen.
          

        


        
        

          
          

            Anda cukup menginstal salah satu server resmi (misalnya `@modelcontextprotocol/server-postgres`) dan menambahkannya ke file konfigurasi client (`claude_desktop_config.json`) dengan menyertakan string koneksi database Anda. Server akan berjalan secara lokal di komputer Anda tanpa mengekspos port ke internet.
